PDP Integration Studio - Vercel Ready

1. Push 3 files/folders in this package to a Git repository.
2. Import the repository into Vercel.
3. Project Settings > Environment Variables:
   OPENAI_API_KEY = your OpenAI project key
   OPENAI_MODEL = gpt-6.1-sol
   MOCK_AI = false
4. Redeploy Production.

The app bundle already contains the processed local corpus index.
